

## 📌 Project Overview

Task Management – JIRA Simulation is a web-based application developed using Java Web Technologies. The application is designed to simplify task management by allowing users to create, assign, update, and track tasks efficiently.

It simulates the basic functionality of JIRA, helping teams organize their work, manage responsibilities, and monitor task progress through a centralized platform.

## 🚀 Technologies Used

- **Frontend:** HTML, CSS, Bootstrap
- **Backend:** Java, Servlets, JSP
- **Database:** MySQL
- **Database Connectivity:** JDBC
- **Server:** Apache Tomcat
- **IDE:** Eclipse
- **Version Control:** Git and GitHub

## ✨ Features

- User Registration and Login
- Role-Based User Management
- Create New Tasks
- View Available Tasks
- Assign Tasks to Users
- Update Existing Tasks
- Manage Task Details
- Store and Retrieve Task Information Using MySQL
- Database Connectivity Using JDBC

## 🏗️ Project Architecture

The project follows the MVC (Model-View-Controller) architecture.

| Component | Responsibility |
|---|---|
| Model | Represents application data |
| View | JSP pages and HTML interfaces |
| Controller | Handles HTTP requests using Servlets |
| DAO | Performs database operations |
| Database | Stores user and task information |
